02 The studio

One person,
one rule
at a time.

ANQURI makes games the way you'd write a proof: state one rule, then spend the whole thing finding out what it forces.

No design document survives contact with a rule that applies every frame. The heat in HEATSINK is not a mechanic bolted onto a shooter — it is the shooter, and everything else in the game exists because that one gauge demanded it. SURVOLT is built the same way, around a different rule: a ball that is worth more every time it changes hands.

Everything is made with Godot 4. The studio also runs its own game server, so that SURVOLT players can find each other without touching their router.
